## 课程与文档

- [ ] 没有密钥、私有配置、个人行程、伪造截图或未执行的成功记录。

## A 行程模块

- [ ] 费用为已知门票之和；存在未知票价时不当作免费，未确定超预算时显示预算待确认；已知费用超过预算时明确提示，允许保存。
- [ ] 非法天数/预算/城市/额外字段、重复/跨城/不存在 ID、重复或缺失日期、每日超额景点返回校验错误。
- [ ] 部分空白日期有提示；全空草案可展示，不可保存。
- [ ] 同一输入的规则推荐确定、偏好优先、不重复；不用凭据和模型网络。
- [ ] 增删或移动后重新校验；请求等待或失败时不会误保存旧内容，过期响应不覆盖新编辑。
- [ ] 只有用户确认才保存；ID/创建时间由服务端生成；刷新或重启可查看，历史保留快照；删除后查询 404。
- [ ] 缺失历史文件视为空，损坏文件报告错误并保留；本地读改写不会因单进程重叠请求丢记录。

## B 景点与规划模块

- [ ] 汕头景点为真实名称，资料标注来源和参考状态，查询筛选和按 ID 排序一致；空结果明确展示。
- [ ] 需求校验与公共模型一致，规划组件按约定事件输出完整景点和标准草案。
- [ ] 规则入口调用 A 服务，没有重复费用和校验实现；普通规则请求不初始化模型。
- [ ] Agent 测试替身能模拟查询、生成、参数校验和输出错误；真实模型调用单独记录。
- [ ] 有凭据时能观察到一次实际只读工具调用和受校验草案；未调用工具或使用工具外 ID 不算 Agent 成功。
- [ ] 调用上限与总超时实际生效，隐式重试关闭；服务/输出失败返回约定错误，前端提示可主动选择规则。

## 整体闭环

- [ ] 页面能输入需求、查看景点、生成、调整、校验、确认保存、查看和删除。
- [ ] 没有密钥仍可完成规则闭环；真实 Agent 可用时前后端无需更改字段。
- [ ] 前端类型检查与构建、后端关键业务/API 测试实际运行；未配置的检查不声称通过。
- [ ] 替身测试、真实联调、设计说明分别记录。只对真实观察作完成声明。
