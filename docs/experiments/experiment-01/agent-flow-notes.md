# 单 Agent 规划业务设计

固定汕头后，用户输入天数、偏好及门票预算。程序校验需求，并从本地景点服务取得资料。规则方式按既定顺序选取编号；可选 LangChain 单 Agent 方式由模型自主调用只读 `search_attractions(city)`，参数限汕头，返回分日候选编号。程序检查编号在本次工具结果中、归属汕头、全程不重复且每日最多两个，按本地数据重算门票，再展示草案。用户调整后重新校验，明确确认后才保存。

规则生成不调用模型；程序先取数据再交给模型属于数据辅助生成；只有观察到模型自主调用工具才可记录 Agent 执行。工具仅查询，不写文件；每请求至多一次工具、两次模型调用。资料不足提示空白日期，全空不可保存；超预算提示但允许用户接受。模型失败、超时或输出非法即报错，由用户主动选择规则方式，不静默降级。模型不得编造景点、价格或擅自保存。

仅为后续可选原型设计，当前实验一不表示已实现或真实调用 Agent。
