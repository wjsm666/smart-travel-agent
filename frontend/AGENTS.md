# 前端开发规则

遵循根 `AGENTS.md`。使用 Vue 3、TypeScript、Vite、Element Plus 和 `pnpm`。A 初始化工程、维护锁文件、`App.vue`、公共类型和 HTTP 客户端；B 完整负责 `modules/planning/`，A 完整负责 `modules/trips/`。

采用 Vue Composition API 和 `<script setup lang="ts">`，局部状态放组件中。HTTP 统一通过 `src/api/client.ts`，无需额外状态库、路由、HTTP 库或图表库。Vite 代理 `/api` 到本地 FastAPI，浏览器中不放模型凭据。

公共类型遵循 `docs/api.md`；模块对接通过 `docs/architecture.md` 的 props 和事件。不要互相导入对方模块内部实现，不自创接口字段。

规划模块向上发出标准草案；行程模块负责编辑、校验、保存和历史记录。调整后的费用必须由后端重新校验后展示；请求未完成或失败时，草案不得以已保存或已校验状态显示。保存按钮在调整未完成校验时禁用。

页面明确说明景点资料非实时、门票估算和规则/AI 推荐来源。未知门票不能显示为免费。技术库名称、调用计数等调试信息放开发记录，不堆入普通用户流程。提供加载、空结果、失败反馈；不静默把规则结果写成 AI 结果。

执行实际配置中的类型检查和构建，必要交互用可复现操作检查；不为低影响样式变化增加重复测试。未初始化工程时不要声称脚本可运行。
